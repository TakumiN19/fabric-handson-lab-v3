# 受講者向け — Microsoft Fabric へのサインイン手順

所要時間: 約 5 分

このハンズオンでは、**ワークショップ用に割り当てられた自分のアカウント**で
Microsoft Fabric（Web ポータル）にサインインします。
ふだん使っている会社・個人アカウントではなく、**当日配布される自分のアカウント**を
使うのがポイントです。

> 🎫 **当日配布されるもの**
> - サインイン用ユーザー名: 自分に割り当てられた配布用メールアドレス
> - パスワード: 当日、講師（facilitator）から共有されます

**先に [Lab 00 の 0-7](00-prerequisites.md#0-7-自分の-student-番号を一度だけ登録する)で student 番号を登録してください。**
Copilot がアカウント名とワークスペース名を自動生成して表示します。このページでは、その表示と照合します。
番号を別の欄に反映する作業は不要ですが、ブラウザでのアカウント選択・パスワード入力は本人が行います。

---

## 💡 いちばん確実な方法: シークレット / InPrivate ウィンドウ

社用 PC などでは、すでに別アカウント（例: 会社アカウント）で Microsoft に
サインイン済みのことがあります。アカウントの混在を避けるため、
**ブラウザのシークレット / InPrivate ウィンドウ**で開くのが最も確実です。

| ブラウザ | ショートカット |
|----------|----------------|
| Microsoft Edge | `Ctrl+Shift+N`（Mac: `⌘+Shift+N`）→ InPrivate ウィンドウ |
| Google Chrome | `Ctrl+Shift+N`（Mac: `⌘+Shift+N`）→ シークレット ウィンドウ |

> シークレット / InPrivate ウィンドウで開いた場合は、**手順 2（サインアウト）は不要**です。
> そのまま **手順 3** に進んでください。

---

## 手順 1. Fabric を開く

ブラウザで次の URL を開きます。

```
https://app.fabric.microsoft.com
```

---

## 手順 2. 別アカウントでサインイン済みの場合はサインアウト

画面右上に**自分以外の名前 / メール**が表示されている場合は、一度サインアウトします。

1. 画面**右上のアカウントアイコン（プロフィール写真）**をクリックします。
2. **Profile（プロファイル）** パネルが開きます。
   - パネルには現在のアカウント名・メール、`Tenant Name`、`License type` などが表示されます。
3. パネル**下部の「Sign out」** ボタンをクリックしてサインアウトします。

> 🔁 サインアウト後、サインイン画面に戻ります。続けて **手順 3** で登録済みのアカウントに切り替えます。
>
> 📷 講師用: 「Profile パネル → Sign out」の画面例を配布資料に添付してください
> （受講者ごとに見え方が異なるため、本手順書には実画面は載せていません）。

---

## 手順 3. 登録済みのアカウントでサインイン

1. サインイン画面で、**Copilot が表示した登録済みのメールアドレス**を選択し「次へ」。候補にない場合は、そのメールアドレスを入力します。
2. 配布された**パスワード**を入力し「サインイン」。
3. サインインできます。**このワークショップ用アカウントは MFA 登録が不要**に設定済みのため、
   通常は **ユーザー名とパスワードだけ**でサインインできます（Microsoft Authenticator の登録は不要）。
   - **「サインインの状態を維持しますか?」**: 共用 / ハンズオン端末では **「いいえ」** を推奨します。
   - 万一 **MFA 登録やパスワード変更を求められた**場合は講師に連絡してください（通常は表示されません）。

---

## 手順 4. サインインを確認する

- 画面**右上のプロフィール**が **登録済みのアカウント**と一致していることを確認します。
- 左側ナビゲーションの **「ワークスペース」** を開き、
  **登録済みのワークスペース名**が表示されることを確認します。

ここまで確認できれば、Microsoft Fabric へのサインインは成功です 🎉

---

## 手順 5. （Power BI ラボ向け）Power BI トライアル（PPU 相当）を開始する

**Lab 05（セマンティックモデル）・Lab 06（Power BI レポート）を実施するには、
ユーザーごとに Power BI の作成権限（Pro / PPU 相当）が必要です。**
Fabric (Free) のままでは、レポートやセマンティックモデルを**作成・発行できません**
（容量を F64 にしても、**作成**には Pro / PPU が必要です。F64 で無料になるのは**閲覧**だけです）。

無償で得るには、**60 日間の Power BI 個人トライアル（PPU 相当）**を開始します。
**この個人トライアルはユーザー単位**なので、**受講者全員が各自で有効化できます（人数の上限なし）**。

1. 画面**右上のアカウントアイコン**をクリックして **Profile** パネルを開きます。
2. **「Start trial」/「Start Fabric trial」** ボタンをクリックして、規約に同意します。
   - ボタンが出ない場合は、Lab 06 でレポートを保存しようとしたときに表示される
     **「60 日間無料で試す（Try paid features free）」** からでも開始できます。
3. トライアルが有効化されると、登録済みのアカウントで Power BI レポート / セマンティックモデルを作成できます。

> 💡 自分のワークスペースは**共有 Fabric 容量（F32）**上にあるため、各自が
> “トライアル容量”を作る必要はありません。必要なのは**個人ライセンス（PPU トライアル）だけ**です。
> （補足: Fabric の **“トライアル容量”はテナント単位で個数に上限**がありますが、
> **個人トライアル（PPU）はユーザー単位で上限なし**です。Lab 02〜04 はトライアルなしの Free でも実施できます。）
>
> ℹ️ 過去に Power BI トライアルを使用済みのアカウントは再取得できません（新規の配布用アカウントは対象）。
> ボタンが出ない・有効化できない場合は講師に連絡してください。

## 🧹 トラブルシュート

| 症状 | 対処 |
|------|------|
| 会社 / 個人アカウントに戻ってしまう | シークレット / InPrivate ウィンドウで開き直す。または Profile → **Sign out** 後に再サインイン |
| サインイン後に MFA 登録を求められる | このワークショップ用アカウントは **MFA 登録不要**に設定済みのため通常は表示されません。出た場合は講師に連絡（アカウントが除外グループに入っているか確認） |
| パスワードの変更を求められる | 画面の指示に従って新しいパスワードを設定（不明なら講師に確認） |
| レポート / セマンティックモデルを作成・保存できない（ライセンス） | **手順 5 の Fabric トライアル（PPU 相当）**を開始する。Fabric (Free) では Power BI レポート・セマンティックモデルは**作成できません**（Lab 05・06） |
| 自分のワークスペースが見えない | 登録済みのアカウントでサインインしているか、右上のプロフィールで確認 |
