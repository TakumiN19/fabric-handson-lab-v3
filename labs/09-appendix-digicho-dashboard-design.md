# Lab 09 — 付録: デジタル庁スタイルにレポートを作り直す（プロンプト駆動）

所要時間: 約 15 分
前提: [Lab 06](06-powerbi-report.md) 完了（`乗車分析レポート` が登録済みのワークスペースに公開済み）

> 💡 **作業指示だけで実行できます。** アカウント・ワークスペース・接続先 ID は Copilot が自動で補います。
> 各プロンプトはそのまま貼り付けてください。設定が見つからない場合は [Lab 00 の 0-7](00-prerequisites.md#0-7-自分の-student-番号を一度だけ登録する)を確認します。

> 🎫 **ライセンス注意**: Power BI レポートの編集には **Pro / PPU 相当**が必要です。
> [Fabric サインイン手順](fabric-portal-login.md) の「手順 5」で **60 日トライアル**を開始してください。

この付録では、Lab 06 で作った `乗車分析レポート` を、
**[デジタル庁 ダッシュボードデザイン実践ガイドブック](https://www.digital.go.jp/resources/dashboard-guidebook)**
の公式デザインテンプレート（**Blue** パレット）風に**作り直し**ます。
やることは Lab 06 と同じく、**プロンプトで指示するだけ**です。

> 🤖 裏側では Copilot が `powerbi-digicho-dashboard-authoring` スキルで公式テーマを登録し、
> `powerbi-report-authoring` スキルで PBIR を組み替え、Fabric REST API で再公開します。

## 📊 この付録で作るデザイン

| 領域 | ビジュアル | 内容 |
|------|-----------|------|
| 左サイド（縦並び） | タイトル / 青ヒーロー KPI / スライサー ×3 / 脚注 | 総乗車件数を青カードで強調、地区・サービスゾーン・乗車月で絞り込み |
| 上段 | KPI カード ×3 | 平均料金・平均合計金額・平均チップ |
| 中段 | ドーナツ / エリア / 縦棒 | 地区別シェア・日次平均料金の推移・時間帯別件数 |
| 下段 | 100% 積み上げ横棒 / テーブル | 地区×サービスゾーン構成比・地区別サマリー（データバー付き） |

> 🎨 角丸グレーカード・左寄せ太字タイトル・青系パレットは**公式テーマが自動適用**します。
> 7 つのパレット（Blue / LightBlue / Cyan / Green / Orange / Red / SolidGray）から選べます。

## 9-1. デジタル庁スタイルに作り直す

> 🗣️ **プロンプト**
> ```text
> 「乗車分析レポート」を、デジタル庁のダッシュボードデザイン
> テンプレート（Blue）風に作り直して。
> - スライサー（地区・サービスゾーン・乗車月）は左に縦に並べてスマートに
> - 総乗車件数は青のヒーロー KPI カードで強調
> - 平均料金・平均合計金額・平均チップの KPI カード
> - 地区別ドーナツ、日次平均料金のエリアチャート、時間帯別の縦棒
> - 地区×サービスゾーンの 100% 積み上げ横棒と、地区別サマリーのテーブル
> 情報量が多いダッシュボードにして。
> ```

🤖 **Copilot の動き**
1. `getDefinition` でレポート定義（PBIR）を取得します。
2. 公式リポジトリ [`digital-go-jp/policy-dashboard-assets`](https://github.com/digital-go-jp/policy-dashboard-assets)
   から **Blue テーマ JSON** を取得し、レポートにカスタムテーマとして登録します。
3. 左スライサー rail + KPI + 各チャートを **1280×720** グリッドに再配置します。
4. `powerbi-report-author validate` でエラー 0 を確認します。
5. `updateDefinition` で登録済みのワークスペースへ再公開します。

✅ **期待する結果**

```text
テーマ「Digital Agency Dashboard Design Template Blue」を登録
レイアウト再構築: 左スライサー rail + KPI×4 + ドーナツ / エリア / 縦棒 / 100%積上げ / テーブル
validate: succeeded（errors: 0）
Status: Succeeded（レポート再公開）
```

> 💡 **KPI はカードではなくテーブル（マトリックス）で**: この Fabric 環境では
> `cardVisual` が空白の箱になり描画に失敗します。Copilot は KPI を
> **`pivotTable`** で作り、ラベルは日本語タイトルで表示します（自動で対応）。

## 9-2. 仕上がりを確認する

**Fabric Portal で開いて確認:**

1. [Fabric Portal](https://app.fabric.microsoft.com) を開く
2. 登録済みのワークスペース → `乗車分析レポート` をクリック
3. 左にスライサーが縦に並び、青いヒーロー KPI とカード・各チャートが
   デジタル庁スタイル（角丸グレーカード・青系）で表示されることを確認
4. スライサーで地区などを選び、全ビジュアルが連動して絞り込まれることを確認

## ✅ チェックポイント

- [ ] レポートにデジタル庁公式テーマ（Blue）が適用された
- [ ] スライサーが左に縦に並んだ（地区・サービスゾーン・乗車月）
- [ ] 総乗車件数が青のヒーロー KPI で表示された
- [ ] ドーナツ / エリア / 縦棒 / 100% 積み上げ横棒 / テーブルが表示された
- [ ] バリデーションが成功し、レポートを再公開できた

---

## 🧹 トラブルシュート

| 症状 | 対処 |
|------|------|
| KPI が空白の箱になる | `cardVisual` ではなく **`pivotTable`** で KPI を作るよう Copilot に伝える（DirectQuery で描画が止まる回避策） |
| テーマ適用でバリデーションエラー | 公式テーマ JSON の不正プロパティ（`barWidth` / `lineStyles` 等）を削除するよう伝える。Power BI 側は無視するが検証は通らない |
| KPI / テーブルの見出しが英語 | 日本語名のメジャー（例 `平均料金 ($)`）を使うか、タイトルで日本語ラベルを付けるよう伝える |
| 描画確認したい（Desktop なし） | 「ExportTo で PDF にして見せて」と伝える（Copilot が PDF 化して確認） |
| 公開が `Failed` になる | 「エラーの詳細を表示して」で原因を確認し、もう一度公開 |
